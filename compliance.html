SMS Program Compliance

This page describes Graceffo Alert messaging behavior for campaign review and recipient transparency.

SMS Program Description

Graceffo Alert is a personal notification program that sends informational SMS messages when Gordon Graceffo enters a St. Louis Cardinals game. Messages are not promotional and are only sent to a fixed, consented recipient list.

Consent

Enrollment requests are collected through Microsoft Forms. Recipients are enrolled only after explicit consent is confirmed through the Enrollment Request Form. Submitting an enrollment request does not create enrollment. Enrollment begins only after manual approval by the application owner. See the Request Enrollment page for the complete workflow.

Message Frequency

Message frequency depends on real game events and may vary. Typical volume is low and event-driven.

Supported Keywords

  • STOP: Unsubscribe from all future Graceffo Alert SMS notifications.
  • START: Re-subscribe if previously opted out and still authorized to receive alerts.
  • HELP: Receive support instructions and project contact details.

Message and Data Rates

Message and data rates may apply according to each recipient's mobile carrier plan.

Privacy

Only phone numbers required for message delivery are stored. No cookies, analytics, advertising identifiers, or behavioral tracking are used.
