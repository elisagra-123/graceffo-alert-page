Request Enrollment

If you have reviewed the SMS Enrollment page and meet the eligibility requirements, you can submit an Enrollment Request Form here. Every request is reviewed manually — only approved requests are added to the notification list.

Submitting a request does not automatically enroll anyone. Enrollment is invitation-only.

Invitation Only

Graceffo Alert is not open for public registration.

Enrollment requests are accepted only from personally known family members and close friends.

Submitting an enrollment request does not guarantee approval.

Enrollment Workflow

  1. 1
    Review Program

    Read the SMS Enrollment page to understand the service, eligibility requirements, required disclosures, and opt-out instructions.

  2. 2
    Submit Enrollment Request

    Complete the Microsoft Enrollment Request Form using the button below. The form collects your contact details and a required consent acknowledgement.

  3. 3
    Manual Review & Approval

    Every submission is reviewed manually. The application owner verifies eligibility and confirms explicit consent before adding any phone number to the approved recipient list.

  4. 4
    Receive Alerts

    Approved recipients begin receiving informational SMS notifications when Gordon Graceffo enters a St. Louis Cardinals game. Reply STOP at any time to unsubscribe immediately.

What Happens Next?

  1. Complete the Enrollment Request Form.
  2. The application owner reviews your request.
  3. If approved, your mobile number is manually added.
  4. SMS notifications begin.
  5. You may reply STOP at any time to unsubscribe.

Submit Your Request

Eligible individuals may request enrollment by completing the Microsoft Enrollment Request Form. Submitting a request does not automatically enroll anyone — only approved requests are added to the notification list.
