Request Enrollment

Graceffo Alert is a private, invitation-only informational SMS notification service. Eligible family members and close friends may submit an Enrollment Request Form to be considered for enrollment.

Submitting a request does not automatically enroll anyone. Every request is reviewed manually. Only approved requests are added to the notification list.

Invitation Only

Graceffo Alert is not open for public registration.

Enrollment requests are accepted only from personally known family members and close friends.

Submitting an enrollment request does not guarantee approval.

Enrollment Workflow

Graceffo Alert uses a deliberate, multi-step process to ensure every recipient has given explicit consent before receiving any messages.

  1. 1
    Learn About Graceffo Alert

    Review this page and the SMS Enrollment page to understand the service, eligibility, and required disclosures.

  2. 2
    Review SMS Enrollment

    Confirm you have read the required SMS disclosures, message frequency notice, and opt-out instructions.

  3. 3
    Complete Enrollment Request

    Eligible individuals complete the Microsoft Enrollment Request Form. The form collects your name, contact information, and a required consent acknowledgement.

  4. 4
    Application Owner Reviews Request

    Every submission is reviewed manually. The application owner verifies eligibility before taking any action.

  5. 5
    Consent Confirmed

    The application owner confirms explicit consent has been provided through the enrollment form before proceeding.

  6. 6
    Manual Approval

    Only after consent is confirmed is the phone number manually added to the approved recipient list. No phone number is ever automatically enrolled.

  7. 7
    Receive Alerts

    Approved recipients begin receiving informational SMS notifications when Gordon Graceffo enters a St. Louis Cardinals game.

What Happens Next?

  1. Complete the Enrollment Request Form.
  2. The application owner reviews your request.
  3. If approved, your mobile number is manually added.
  4. SMS notifications begin.
  5. You may reply STOP at any time.

Request Enrollment

Eligible individuals may request enrollment by completing the Microsoft Enrollment Request Form. Submitting a request does not automatically enroll anyone. Every request is reviewed manually, and only approved requests are added to the notification list.

Request Enrollment

Enrollment Request Form

The Enrollment Request Form is hosted securely by Microsoft Forms. The form collects the following information:

  • First Name
  • Last Name
  • Email Address
  • Mobile Phone Number
  • Relationship to Gordon Graceffo (optional)
  • Reason for Request (optional)

The form includes a required consent acknowledgement confirming:

  • You are requesting enrollment in Graceffo Alert informational SMS notifications
  • Messages are informational only — no marketing, no advertising, no fundraising
  • Enrollment requires manual approval
  • Message frequency varies
  • Message and data rates may apply
  • Reply STOP to unsubscribe at any time
  • Reply HELP for assistance
  • Consent is not required to purchase any goods or services

Enrollment Questions

How do I request enrollment?

Complete the Enrollment Request Form by clicking the Request Enrollment button above. If your request is approved, your mobile number will be manually added after confirming your consent.

Does submitting the form enroll me?

No. The form only requests enrollment. Enrollment requires manual approval. You will not receive SMS messages unless your request is approved.

Who can request enrollment?

Graceffo Alert is limited to personally known family members and close friends. The service is not open to the general public.

What happens after I submit?

Your request is reviewed manually by the application owner. If approved, your phone number is manually added to the notification list. Only then will informational SMS notifications begin.

How do I opt out?

Reply STOP at any time to unsubscribe immediately. You may also contact graceffoalert@outlook.com to request removal.

How do I get help?

Reply HELP for support information. You may also contact graceffoalert@outlook.com for assistance with enrollment questions.
